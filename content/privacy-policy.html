Effective October 3, 2026. This page explains what Voiceboard collects and where it goes. The short version: the game board keeps most of its data in your browser, saves a short game record on this site for 30 days, and we don't run ads, analytics, or tracking.

What stays in your browser

The board saves a few things in your browser's local storage so a game can continue from one screen to the next:

  • player names and scores that your voice assistant put in the game's URLs
  • the winners of your last 20 finished games, shown in the Hall of Fame
  • your theme choice
  • a random ID for this screen, used only to tell game boards apart

You can clear it at any time by clearing this site's data in your browser. The New game button and a game URL with reset=1 clear the saved players.

Game records on this site

Each time the board shows a screen, it sends this site the game's state: the screen's web address, the game, player names (gamer tags for that game) and scores, the current question and answer, whose turn it is, the screen's random ID, and notes about anything in the address the board couldn't use. We keep these as a game record under the session code your assistant chose (or the screen's random ID), so the assistant can read the game back. We also note the browser type, such as a car's software version, and, while a board is open, which game boards are connected. We don't store IP addresses with game records. Game records are deleted automatically 30 days after the last screen, and only site administrators can see them in the dashboard; anyone who knows a session code can read that session's summary.

What reaches our server

Every screen is a web address, so whatever your assistant puts in that address (player names, questions, answers) is part of the request your browser makes to this site. Like any website, our hosting provider's servers record requests, including the address, your IP address, your browser type, and the time, and keep these logs for a limited period for security and operations. Use first names or nicknames for players if you'd rather not include full names.

Cookies

Playing sets no cookies. WordPress sets cookies only for people who log in to manage the site, and its activity features record what logged-in administrators are doing in the dashboard, not visitors.

Your voice assistant

We never receive audio. Your voice and your conversation are handled by your assistant's provider under its own privacy policy; we see only the web addresses it opens.

Children

The games are made for all ages. We don't knowingly collect personal information from children, and we don't ask anyone to create an account.

Changes

We'll update this page before collecting anything new and change the effective date above whenever the policy changes.
